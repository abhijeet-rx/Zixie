# Zixie sample submissions (20 files)

All submissions are synthetic examples written for testing. They do not contain real student or employee work.

The 20 JavaScript files cover five small programming tasks, with four approaches for each task:

- Binary search: files 01–04. Files 01 and 02 use nearly the same iterative approach with renamed variables. File 03 is recursive; file 04 uses a simple scan.
- Word counting: files 05–08. Files 05 and 06 use nearly the same counting approach with renamed variables. Files 07 and 08 use different ways to split and count words.
- Palindrome checking: files 09–12. Files 09 and 10 use nearly the same two-pointer approach with renamed variables. Files 11 and 12 use different approaches and rules.
- Merging sorted lists: files 13–16. Files 13 and 14 use nearly the same two-pointer merge. Files 15 and 16 combine then sort.
- Matrix transpose: files 17–20. Files 17 and 18 use nearly the same nested-loop approach with renamed variables. Files 19 and 20 use different approaches.

For comparisons, upload all 20 files together. Review the results rather than treating a high score as proof of copying: the groups include different solutions to the same task, so some shared code is expected.
